# 🧭 MBTI 진로 탐색소

고등학생이 MBTI 유형을 선택하면 유형별 강점을 바탕으로 직업 3가지를 추천하는 단일 화면 Streamlit 앱입니다.

## 실행 방법

```bash
streamlit run app.py
```

## GitHub · Streamlit 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `app.py`를 저장소에 업로드합니다.
3. Streamlit Community Cloud에서 저장소를 연결합니다.
4. Main file path를 `app.py`로 지정하고 배포합니다.

## 구성

- `app.py`: 전체 앱 코드
- 추가 페이지와 외부 패키지 없음
- Python 표준 기능과 Streamlit만 사용

> MBTI 추천은 진로 탐색을 돕는 참고 자료이며, 개인의 적성·흥미·가치관을 확정하거나 제한하지 않습니다.
